# POMEPET

面向手机浏览器的宠物生活管理网页应用，底部导航为今日、记账、档案、我的。

## 功能

- 生活记录时间线、分类筛选、照片、编辑和删除。
- 单次、固定周期和完成后间隔照护安排；完成后生成记录及下次安排。
- 养宠账本、退款、多宠分摊、公共支出、累计投入和账单分析。
- 多宠物档案、资料编辑、健康记录与根据到家日更新的陪伴天数。
- 成长合集自动收集记录照片，掉落后错落堆积，支持预览和查看原记录。
- 自定义事项名称、分类及 emoji；悬浮新增按钮在滑动时半隐藏。
- 宠物照片自动抠图、透明留白裁剪；宠物档案左滑删除与恢复。
- JSON 备份导出与恢复、记录 CSV 导出。

## 本地运行

安装 Node.js 后执行：

```bash
node server.mjs
```

打开 http://localhost:4173 。部署文件位于 `dist/`，可用于静态网站托管。运行已构建版本无需安装依赖。

```bash
node --test tests/*.test.mjs
```

当前包含 13 项自动检查。成长合集动画尚需手机端视觉验收。

`?demo=1` 使用独立 sessionStorage 示例数据，不修改真实记录。

## 数据与账号

数据存储在当前浏览器的 localStorage，照片在本机处理。更换网址、设备或浏览器时，请先导出备份，再在新位置恢复。

首页“注册”目前进入宠物资料创建流程，不创建账号；尚未接入账号系统和跨设备云同步。网页关闭后的提醒不能保证触发。

## 项目结构

- `dist/`：网页、业务模块、样式、设计素材和已构建图片处理依赖。
- `scripts/`：图片处理库构建脚本。
- `tests/`：业务逻辑检查。
- `server.mjs`：本地预览服务。

## 图片处理依赖与许可

自动抠图使用 @imgly/background-removal 1.7.0（AGPL-3.0）。源码、许可及第三方许可保留在 `dist/vendor/`，请按相关许可使用和分发。

首次抠图需要从 IMG.LY 下载模型和运行资源。照片在当前设备处理，失败时可保留原图。

需要重新构建图片处理库时：

```bash
pnpm install
pnpm build:cutout
```

本仓库不包含个人数据备份、验证截图、node_modules、发布压缩包或 Sites 托管配置。
